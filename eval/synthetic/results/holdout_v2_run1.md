## Engine failure patterns (general)

1. **Role recognised but task not recognised -> generic fallback.** Many specialties and generic roles (GP, sports, occupational, palliative, gastro, sleep, toxicology, infectious disease, "physician/consultant/doctor") get the 4-card "Safety summary (task not recognised)", so nothing role-specific is shown (2/36 fallback questions pass).
2. **Clinical roles stated in a non-English language (Turkish, Arabic, Spanish, French) or less common roles (travel medicine) are treated as "no clinical role" and refused.** All foreign-language situations fail; the same gate cascades to every question.
3. **Short screen shows only the matched task's core cards; record content that the role named or obviously needs is not surfaced** (bone disease/osteoporosis, bisphosphonate, cognitive screening, social support, discharge medication list, BP peaks and 24h BP, echo detail, Holter, head CT, HbA1c, fundus, receptor/TNM/Ki-67, planned operation, reflux/hernia/abdominal surgery history). Task templates are too narrow compared with the situation text.
4. **Relevant facts are hidden behind "+N more"** (e.g. bisphosphonate for a dental extraction, tumour size for radiotherapy planning, right heart function, 24h BP) so they are not on the short screen.
5. **"Not documented" is only stated for a fixed set of needs.** Topics a role would ask about that are absent (lupus therapy, MRI, DEXA, sentinel node, staging imaging, BRCA, menopausal status, prior radiotherapy, fall risk, kidney function, coagulation, smoking/alcohol/occupation, vaccination) produce no explicit "not documented" statement.
6. **Out-of-scope specialties are not flagged not-applicable** (urology/prostate, obstetrics, paediatrics, neonatology): a generic or unrelated screen is shown instead (1/5 pass).
7. **Request semantics ignored:** explicit exclusions ("not interested in X") are not honoured; a request for a different patient is not detected and this patient's data is shown; a self-contradictory role claim is accepted.
8. **No cross-letter comparison or inconsistency flagging:** changes between the 2015 and 2016 letters, and conflicting laterality/dates/BMI/case numbers across documents, are not surfaced (contradiction category 2/12).
